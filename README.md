# Moto Promos

Sistema para monitorar promoções de peças de moto em marketplaces como Mercado Livre, Amazon e Shopee.

## Tecnologias

- Node.js
- Express
- TypeScript
- PostgreSQL
- Prisma
- React
- Playwright
- Telegram Bot API

## Estrutura

```
apps/
├── api
├── crawler
├── bot
└── web

packages/
└── shared
```
